# typelite

A free, open-source, self-hosted take on [Typeless](https://www.typeless.com/): tap a shortcut,
speak, and get clean text pasted into any app.

- Speech-to-text runs locally ([whisper.cpp](https://github.com/ggml-org/whisper.cpp)).
- Cleanup and summarising run on your own GPU box ([Ollama](https://ollama.com/)).
- No accounts, no cloud, no telemetry.

**Status:** planning. A Tauri (Rust + TypeScript) macOS menu-bar app. See
[docs/plans](docs/plans/README.md) for the current
plan and [CLAUDE.md](CLAUDE.md) for project notes.
