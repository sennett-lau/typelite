# Guides

Typelite needs two services: one that turns speech into text, and one that polishes the text.
Both speak the OpenAI-compatible API, so you can run them yourself or use a cloud service with
your own key.

| Guide | Covers |
|---|---|
| [Speech recognition](speech-recognition.md) | whisper.cpp on this Mac, a GPU server on your network, or a cloud key. |
| [AI polish](ai-polish.md) | Ollama on this Mac or another computer, or a cloud key. |
