What to look at
  • Onboarding has one main button (Set up), one link (your own server or key) and Skip.
  • The Built-in card has a fixed height in every state. It offers only the models this Mac can run well; with one model there is nothing to choose. Try the "Simulate Mac" buttons.
  • The link opens a sheet. With saved presets it lists them first; with none it opens straight on the form: four fields with the OpenAI example as placeholders, and "Learn more" linking to the services guide on GitHub.
  • Settings sections are toolbar tabs (icon + label) across the top, as in macOS Settings windows. "Speech recognition uses" is a choice between two cards, not tabs: the selected card is the engine in use, and its details show below.
  • Settings uses the same pieces as onboarding: Built-in shows the model cards this Mac can run, with a status row (Not downloaded, Downloading, In use, Failed); Presets uses the same four fields, placeholders and Learn more, with the saved-preset picker at the top right, or the Add form when there are none.
