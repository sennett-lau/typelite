When there's nowhere to paste

If no text field has focus when the result is ready, the pill stays up and shows the start of the text with a Copy button instead of pasting into nothing.

How it behaves
  • Text field focused: no change. Paste, a short "Done" flash, the pill hides.
  • No text field: Typelite doesn't paste. The pill grows, shows the start of the result and a Copy button. It stays 8 s; hovering pauses it, Esc closes it.
  • Countdown options: 1 draws the line only under the text, so it never reaches the button; 2 keeps the full-width line and shrinks the button so they no longer touch; 3 drops the line and runs the countdown around the Copy button's border (recommended: nothing extra in the pill, and the timer sits where your eye already is).
  • Transitions: the pill's width, height and corners animate together; the old label fades out while the new one fades in (a slight blur, 0.2 s); the working light fades rather than cutting; hiding slides down and fades.
  • Copy puts the full result on the clipboard, shows "Copied", and the pill hides a moment later. The clipboard is not restored afterwards, since you asked for it.
  • Clicking the pill never takes focus away from the app you're in.
  • Hover to pause, then try the Copy button. Replay runs the sequence again.
