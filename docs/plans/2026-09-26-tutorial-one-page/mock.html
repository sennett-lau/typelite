What changed from today's design
  • The shortcut (and, for Translate, the language) is set on its own page. Each exercise then has its own page: the line to read, one box where the text lands, and one result line.
  • After a run: "Typelite is writing…" while the text is typed into the box; the result appears only once the text has fully arrived. On success, the "Read this" card turns into a green result card that shows what changed (removed words struck through, or before → after).
  • Next, Skip and Back live in the footer; "Try again" is a link on the result line. Next unlocks after a success (Skip always works).
  • Ask's question exercise has no box: the answer opens in the Ask window, shown at the right.
  • Title and content are one block, centred between the step dots (top) and the Back/Next footer (bottom), with 22 pt between the title and the content. Try Window height → 900 to see an enlarged window.
  • The step dots now count 3 pages per shortcut (setup + 2 exercises).
  • The pill preview shows the recording aurora inside the pill (as in the app), so it stands out in light and dark. It grows with the language name; only names wider than about 180 pt scroll as a continuous marquee to the left.
  • Translate keys: the first key of the Translate shortcut stops (Fn); the Switch language key switches (⇧ by default, follows Settings). Pressing the whole shortcut again also stops. The hints name each key by its job.
  • Agreed for Translate setup: no language by default (Try it disabled until one is added; the pill preview still shows, without a language name); the list is three slots in one row (empty slot = "+ Add", no add button at three); the pill shows the active language name plus one dot per language (B); a name that does not fit slides back and forth (plain ellipsis with Reduce Motion); the hint names the user's own Switch language key.
  • Setup pages only set the keys. Recording is always press to start, press again to stop; hold-to-talk stays in Settings → General.
