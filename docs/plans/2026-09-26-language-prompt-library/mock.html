Language presets from GitHub

Each translation language can use a preset from the project's library on GitHub, the built-in default, or your own text. Presets are plain prompt text; you see every text before it is used, and updates apply by themselves only for a language whose auto-update you turned on (and never over text you edited).

How it works
  • Where the text comes from, in order: your own edited text, else a downloaded preset, else the built-in default (always available offline).
  • Adding a language opens its sheet; "Browse presets" lists matching presets from GitHub: Official first, then Community, most specific language first. English (UK) shows the shared English preset with its en-GB notes.
  • Nothing is used before you see it: choosing a preset shows its full text first; "Use this preset" applies it.
  • Editing keeps a local copy ("Based on … · edited"); "Reset to preset" undoes your edits, "Reset to default" returns to the built-in text.
  • Updates: with "Update presets automatically" on, Typelite checks GitHub once a day and applies new versions of presets you haven’t edited; edited text is never replaced (the sheet offers “Use v4 instead”). With it off, a dot on the language and a banner offer Preview / Update.
  • In Settings, languages are rows (number, name, where its instructions come from, model, Edit, remove, drag to reorder), with “+ Add language” as the last row until there are 3. The one-row slots stay in onboarding only.
  • The Translation section no longer explains itself inline; “About language presets” links to the guide, and each language sheet says what the instructions are for.
  • Recognition (polish only): the router chooses one of your languages or Other. 1) A hint character/word matches → that language. 2) Else the language speech recognition reported matches one of your languages → that one (a preset can require a hint, e.g. Cantonese, so plain Chinese does not get Cantonese rules). 3) Else plain polish, no extra instructions. Hints and codes come from the preset; you can add your own. Nothing language-specific is built into the app.
  • One switch per language (on the row and at the top of its sheet): on = its instructions are used for both translating into it and polishing speech in it; off = plain translation and no extra polish instructions. No per-language AI model (prompts only for now).
  • Downloads are plain GETs from GitHub with no identifiers; each file is checked against the hash in the library's index.
