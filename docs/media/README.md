# Media

The images and GIFs for the project README and the guides go in this folder. They are not
captured by hand: they are rendered from the capture pages of the project site (HTML and React
mock-ups of the app's windows), so they can be regenerated whenever the UI changes.

Conventions for the generated files:

- Stills are PNG, 1600 px wide. Moving shots are GIF or MP4, at most 8 MB.
- Where it matters, render both themes and add `-light` or `-dark` to the file name.
- Use neutral example text, generic preset names and documentation addresses such as
  `192.0.2.10`: never real names, host names, addresses or keys.

The README has a commented-out hero image block near the top. Uncomment it and point it at the
file once the file exists here, so the README never shows a broken image.
